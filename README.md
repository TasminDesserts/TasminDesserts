## 📌 Overview

This repository contains the full front-end source for **Tasmin Desserts**, a handcrafted dessert brand site built to showcase products, tell the brand story, and let visitors build and submit a custom order — all without a backend server.

## ✨ Features

- 🏠 **Home / Hero** — animated landing section introducing the brand
- 👩‍🍳 **About & Owner** — brand story and the person behind the desserts
- 🧁 **Specialties** — categorized dessert menu (cakes, pastries, custom creations, and more)
- 🛒 **Order Builder** — add items to a floating cart, adjust quantities, and review before submitting
- 🖼️ **Gallery** — lightbox-style image gallery for finished creations and custom orders
- 🌗 **Dark Mode Toggle** — light/dark theme saved across visits
- 📱 **Fully Responsive** — mobile-friendly navigation and layout
- 📩 **Contact Section** — ways to get in touch for orders and inquiries
- 📰 **Recent Posts** — embedded social feed for latest updates

## 🗂️ Project Structure

| Folder / File | Description |
| :--- | :--- |
| `index.html` | Main site markup and structure |
| `Styles/style.css` | All site styling |
| `Scripts/script.js` | Site interactivity — cart logic, gallery modal, theme toggle, animations |
| `Pictures/` | Product photos, gallery images, branding assets (logo, favicon, cover, QR code) |

## 🛠️ Built With

- **HTML5 / CSS3 / JavaScript** — core site
- **AOS (Animate On Scroll)** — scroll-triggered animations
- **Swiper.js** — image/content sliders
- **Font Awesome** — iconography
- **Google Fonts** (Poppins, Playfair Display) — typography

## 🚀 How to Use

1. **Clone the repository:**

    git clone https://github.com/TasminDesserts/TasminDesserts.git

2. **Navigate to the project directory:**

    cd TasminDesserts

3. **Open `index.html`** directly in your browser, or serve it locally with any static server (e.g. VS Code Live Server) for the best experience with routing and asset loading.
